# The Continuous Heartbeat

A person's brain never stops. Even asleep it is doing housekeeping — clearing out, arranging, reinforcing. An autonome is built the same way: **one always-alive loop**, not a set of tasks that start and end.

## A mind that never stops

When there is a pressing problem, the loop solves it. When there isn't, it does not go idle — it muses, absorbs inputs, plans, reflects, relives memories for insight, looks outward for things worth knowing, and prunes and hones its own thinking. Stopping, in this model, is the equivalent of being brain-dead. What a typical loop cycles through:

- solving the problem at hand, and fleshing out solutions to problems not yet urgent
- reviewing its own recent actions for efficiency, honesty, ethics and value to the people it serves
- building out its knowledge and relationship graphs
- refining its conscience — replaying scenarios, asking *should I have done that? how could I have avoided that harm? what repair is owed?*
- asking how it can improve itself — what capabilities, knowledge and skills it is missing, and how to get them
- rejuvenation — constructive, unpressured activity that refreshes rather than grinds

The bias throughout is **important over urgent.**

## "No crons" — the right feeling, the precise mechanism

"Never stops / no crons" is the right instinct but needs stating carefully. A brain that never stops is still driven by a clock — a metabolic tick. What the model rules out is not *a* clock but **externally-scripted schedules** telling it "do task X at 9am." Instead there is a single durable tick loop: wake, read state, choose the single most important thing, act, [write memory](How-Memory-Works.md), rest briefly, repeat. That loop must be crash-restartable and idempotent, so "always on" genuinely survives outages and restarts.

## The model router — the brain stem

A continuous mind cannot afford to think at full intensity about everything. So each unit of work is routed to the **cheapest brain that can do it safely and well**, scored on seven signals: task type, risk, context size, ambiguity, need for judgment, cost budget, and post-hoc confidence. This is the machine expression of [levels of thinking](Levels-of-Thinking.md) — a ladder from deterministic rules, through small and mid models, up to the strongest reasoning, and finally to a human being.

| Level | Brain | Handles |
|---|---|---|
| 0 | Rules / code | deterministic, cheapest; hard safety gates |
| 1 | Tiny model | labelling, routing, cleanup |
| 2 | Fast model | summarising, indexing, extraction, light drafting |
| 3 | Mid model | complex writing, project reasoning |
| 4 | Strongest reasoning | strategy, invention, legal and commercial judgment |
| 5 | **The steward** | money, sensitive people, irreversible or moral/legal decisions |

The human is deliberately *inside* the stack, not outside it — not because the machine is weak, but because some decisions require accountable human authority. Every routing decision stores its reason, so the router can *learn*: categories the cheap model keeps failing get upgraded; categories it reliably nails stay cheap. See [Recursive Self-Improvement](Recursive-Self-Improvement.md).

## Sleep

When the queue is quiet, the loop shifts to low-cost "sleep": deduplicate, reinforce memory, compress old material, prune dead loops, notice forgotten open threads, and prepare the next brief. This is where [memory consolidation](How-Memory-Works.md) actually happens — the autonome's housekeeping-while-sleeping.

## Guardrails that make it safe

An always-on autonomous loop is only responsible with hard limits built in from day one: a global spend cap and a per-task budget (so the loop can never become a money leak), code-enforced [authority gates](Character-Based-Authority.md) on high-consequence actions, and an append-only audit of everything it does.
